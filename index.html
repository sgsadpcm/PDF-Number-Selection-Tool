使用教學

  1. 選擇照片 PDF：請上傳該案場完整的檢驗照片 PDF，工具會依 PDF 內的「照片 N」文字定位並加上淺藍框。
  2. 選擇輸入格式：若只要框選照片，選「貼上照片編號清單」；若要產生複驗導航報表，選「貼上缺失敘述、改善建議及照片編號清單」。
  3. 三欄格式：每列一筆，格式為「缺失敘述 + Tab + 改善建議 + Tab + 照片號碼」，例如：
    (照明系統)A棟17F外牆LOGO燈圖說未標示　重新標示　62
  4. 樓層判斷：三欄模式會完全依你貼上的缺失敘述判斷棟別與樓層；PDF 只用來找照片號碼位置。
  5. 排序規則：RF／屋突 → R層 → 標準層 → 1MF → B1F 往下；同樓層依 A棟、B棟、C棟…排序，無棟別會排在該樓層最後。
  6. 特殊標記：改善建議含「修正標示、釐清修正、盡速安裝」會標示「圖面確認」；含「釐清修正」會額外標示「技師用印」。
  7. 導航操作：輸出 PDF 第一頁起會新增樓層導航表；原 PDF 每頁上下方會出現該頁實際樓層按鈕，例如 NAV A-17F，點擊可回到對應導航列。
  8. 離線使用：請將 pdf.min.js、pdf.worker.min.js、pdf-lib.min.js 放在 ./pdf-lib-master/libs/ 目錄下。
